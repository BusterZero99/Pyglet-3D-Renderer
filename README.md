# Pyglet-3D-Renderer
A 3D model renderer built using Pyglet in Python.

* Place a .obj model file into the folder labeled "models"

* Use trackpad or scrollwheel to zoom in.
* Use up and down arrow keys to move the camera.

* Requires Pyglet and Numpy
